# 工具协议与安全边界

## AI 工具使用

允许使用 AI 工具辅助：

- 结构分析
- 文案生成
- 素材标签整理
- 前端和后端编码
- 报告生成

需要在最终说明文档中披露：

- 使用了哪些工具
- 分别用于哪些环节
- 哪些能力是自主设计和实现

## 密钥管理

- API Key 只放在 `.env` 或部署平台 Secret。
- 不把密钥写入代码、mock、README、截图。
- `.env.example` 只保留变量名。

## 内容边界

系统强调结构迁移，不复制样例视频的具体内容。

允许迁移：

- 段落顺序
- 节奏曲线
- 字幕密度
- 包装方式
- CTA 位置

不应直接复制：

- 样例原文案
- 原视频素材
- 原品牌包装元素
- 未授权音乐和图像

## 模型调用边界

- 默认使用配置中的主模型。
- 模型失败时返回 mock 或缓存结果，保证演示链路不断。
- 大视频生成模型只作为可选补全，不作为主链路依赖。
- 模型输出必须经过 schema 校验再进入下游。
